# NCR Cooling Centre - Official Website

Doorstep Appliance Repair Services in Gurgaon & Delhi NCR.
Specializing in AC Repair & Gas Filling, Refrigerator, Geyser, Washing Machine, and Microwave Repair.

## Tech Stack
- Next.js (App Router)
- React 19 & TypeScript
- Tailwind CSS
- Lucide React

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
